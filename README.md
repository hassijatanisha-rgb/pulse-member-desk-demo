# Pulse Member Desk — public concept demo

This repository is the reviewed static artifact for the fictional-data demonstration at `https://hassijatanisha-rgb.github.io/pulse-member-desk-demo/`.

It stores demo entries only in the current browser session and has no server, analytics, account system, inbox connection, or live customer data. The private product repository contains the separately installable client-owned Google Apps Script application and is not published here.
